### Persyaratan
- PHP 8.x
- XAMPP atau server PHP lokal
- Browser dan editor kode

### Cara menjalankan
1. Ekstrak folder proyek ke `C:\xampp\htdocs\` (Windows).
2. Jalankan Apache melalui XAMPP.
3. Buka `http://localhost/PBO_Pertemuan_4_Rafy_Adilaputra/` untuk halaman daftar percobaan.
4. Pilih percobaan yang ingin dijalankan. Setiap percobaan juga dapat dibuka langsung melalui nama file PHP-nya.

### Daftar percobaan
- `constructor.php`: constructor dengan parameter fakultas default.
- `buku.php`: class Buku dengan tiga objek.
- `destructor.php`: destructor dan pengaruh alias terhadap `unset()`.
- `atribut_dinamis.php`: `__set()`, `__get()`, `__isset()`, dan `__unset()`.
- `overloading_method.php`: penggunaan `__call()` dan pengujian exception.
